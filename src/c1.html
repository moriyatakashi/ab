01

今の ab/src/ は index.html 1本だけ(aa の srt.html への案内のみ)。ここに新しくフォルダを切ります。

ab/ ├── index.html おまちください(トップ) ├── style.css └── src/ ├── index.html 既存・aaへの案内 ├── c1.html このページ └── ca/ ← 新設(予定) └── index.html ca の実体(サイト側は後で)
ストレージテーブルは要るか / API は要るか
→

どちらも要る、というのが今の見立てです。「ba的な追記型スレッド」を名乗る以上、書き込みが前提。書き込みがある時点で、認証を挟むサーバー(API)と、消えない置き場(テーブル)がセットで要ります。

逆に言うと、もし ca が当面「読むだけ・書かない」なら、どちらも今は不要で index.html だけで足ります。ここの前提(書き込み前提かどうか)を先に確認したいところです。

Function App 自体は増やさない(インフラ増設なし)。テーブルとエンドポイントだけ ca 用に足す、が最小構成。
